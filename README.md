# Replypilot

ReplyPilot is a tiny demo web app that helps you craft professional replies quickly. Enter a message or email text into the input, click "Generate Reply", and the page will produce three professional reply options (Short, Formal, Friendly) that you can copy and use.

How to use

1. Open index.html in your browser (or host the project on any static hosting).
2. Paste or type the message you want to reply to in the text box.
3. Click the "Generate Reply" button — three reply options will appear.
4. Click "Copy" next to any reply to copy it to your clipboard.

Notes

- This is a client-side demo that generates templated suggestions — it's not connected to any AI service.
- You can adapt the reply templates in `index.html`'s JavaScript to match your tone and style.
